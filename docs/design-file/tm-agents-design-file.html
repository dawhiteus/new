Transaction Manager Agents — Design File

Every screen state of the three TM agents: Requirement Agent, Create Collection and Assess Collection. Screens are drawn from the working prototype (Nov 2026) at their real widths, with the prototype's colors, type and copy. Frame IDs match the state IDs in docs/design-reference/; frames those files don’t list (such as T1, UC1 and AS1) are additions. Use cases in brackets match the engineering specs.

Sample data is illustrative (the Northwind Analytics Austin requirement). Animated states (spinners) are shown mid-animation.
